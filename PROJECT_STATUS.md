# Project status and hackathon compliance

This folder is a runnable learning proof of concept. It is **not a ready-to-submit or verified-compliant entry** for Devpost Build With AI: Basics.

Before any competition submission, personally:
1. Verify age/eligibility and all current official rules.
2. Start from an empty folder during the permitted submission period, as required by the event.
3. Install and use the official Devpost Learn Skill Pack inside a supported coding agent.
4. Follow its interview/planning/build/ship process and retain the generated planning documents (`scope.md`, `prd.md`, `spec.md`) in the required repository locations.
5. Test, publish the repository, record a demo, and accurately describe what you built and learned.

Do not claim that the official skill pack was used unless you actually used it. This starter project is supplied to help you learn and inspect a possible product direction.
